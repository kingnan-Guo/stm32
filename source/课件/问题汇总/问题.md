2、引入 stdarg 

```c
/**
 * 可变参数 把printf 变成 可变参数
 * @param format 用来接收 格式化字符串
 * @param ... 用来接收后面的额可变参数列表
 *
 * 1、定义输出的字符串
 * 
 */
void Serial_Print(char *format, ...){
    // 定义输出的字符串
    char String[100];
    //定义一个参数列表变量 va_list 类型名 arg变量名
    va_list arg;
    // 从 format 位置开始接收参数表， 房子啊arg 里面
    va_start(arg, format);
    // vsprintf 打印位置是 String 格式化字符串 format； 参数 arg
    vsprintf(String, format, arg);
    va_end(arg);
    Serial_SendString(String);
}


```

编译后依然报错

添加这段后
```cmake
# 添加这段 之后 可以 使用引入的 "stdarg.h"
set(CMAKE_SHARED_LIBRARY_LINK_C_FLAGS "")
set(CMAKE_SHARED_LIBRARY_LINK_CXX_FLAGS "")
#CMAKE_EXE_LINKER_FLAGS 用于创建可执行文件的链接器标志； 链接器在创建可执行文件时将使用这些标志
set(CMAKE_EXE_LINKER_FLAGS " -specs=rdimon.specs -lgcc -lc -lm -lrdimon")
```

可以正常编译 并且 输出串口打印

4、按照下面这篇文章 在 USART_PRINTF 分支上修改 重定向和 cmake 以解决 printf 不生效的问题
[【教程】手把手教你用Clion进行STM32开发【如何优雅の进行嵌入式开发】](https://zhuanlan.zhihu.com/p/628628503)


```markdown
1、首先 添加 system/syscalls/syscalls.c 因为 如果没有 这些函数；   会有 上面的 报错； 通过观察错误信息可以定位undefined reference to '_xxx'，很显然因为我们使用的是ARM_GCC，而Keil是ARMCC，两者的库不一样，ARM_GCC缺少了这些定义导致这样重定向无法使用。
2、添加这些函数后，打包不会报错了，但是串口依然无法打印
3、在GCC编译器中(stm32标准库)需要重定义的是__io_putchar(int ch)，而这个函数，在_write中被使用，即syscalls.c中重写了_write()函数。 如果在keil5 中 才会去重定向 fputc
4、 所以 在 system/retarget/retarget.c 中  重定向 __io_putchar(int ch) 和  __io_getchar (void)
5、 还要解决 禁用半主机，添加禁用半主机模式相关代码到  /* 告知连接器不从C库链接使用半主机的函数 */ #pragma import(__use_no_semihosting)
```


5、引申问题
setvbuf
在 system/retarget/retarget.c  有使用 setvbuf； 
具体作用  文件中有备注，在这里记录一下 setvbuf 用法

```markdown
setbuf()和setvbuf()函数的实际意义在于：
    用户打开一个文件后，可以建立自己的文件缓冲区，而不必使用fopen()函数打开文件时设定的默认缓冲区。
    这样就可以让用户自己来控制缓冲区，包括改变缓冲区大小、定时刷新缓冲区、改变缓冲区类型、删除流中默认的缓冲区、为不带缓冲区的流开辟缓冲区等。
    原文链接：https://blog.csdn.net/Michaelwubo/article/details/41244323

```
示例代码：
这将产生以下结果。在这里，程序把缓冲输出保存到 buff，直到首次调用 fflush() 为止，然后开始缓冲输出，最后休眠 5 秒钟。它会在程序结束之前，发送剩余的输出到 STDOUT
```c
#include <stdio.h>
#include <unistd.h>
#include <string.h>
int main()
{
 
   char buff[1024];
 
   memset( buff, '\0', sizeof( buff ));
 
   fprintf(stdout, "启用全缓冲\n");
   setvbuf(stdout, buff, _IOFBF, 1024);
 
   fprintf(stdout, "这里是 runoob.com\n");
   fprintf(stdout, "该输出将保存到 buff\n");
   fflush( stdout );
 
   fprintf(stdout, "这将在编程时出现\n");
   fprintf(stdout, "最后休眠五秒钟\n");
 
   sleep(5);
 
   return(0);
}

//启用全缓冲
//这里是 runoob.com
//该输出将保存到 buff
//这将在编程时出现
//最后休眠五秒钟
```
